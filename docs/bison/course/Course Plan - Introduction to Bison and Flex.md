# **Course Plan: Introduction to Bison and Flex**

**Course Title:** Introduction to Bion and Flex: Building a C to XML Parser

**Duration:** 60 Minutes.

**Target Audience:** Developers, Computer Science students, or enthusiasts with basic knowledge of C programming and compiler theory concepts (tokens, parsing, context-free grammars).

**Objective:** By the end of this session, students will understand the core concepts of Flex and Bison and will have a foundational codebase to build a lexer and parser for a subset of the C language, outputting an XML representation of the parsed code.

**Instructor Materials:** A pre-configured Linux/macOS terminal or Windows WSL with `flex` and `bison` installed. A code editor (e.g., VSCode, Vim). Prepared code snippets for each step.

**Student Prerequisites:** Basic C knowledge, familiarity with the command line.

## **Detailed Content for Key Sections**

### **Part 1: Lex Example (`c_lexer.l` snippet)**
```lex
%{
#include "c_parser.tab.h" // Header generated by Bison
%}

%%
"int"       { return INT; }
"if"        { return IF; }
"while"     { return WHILE; }
"{"         { return LBRACE; }
"}"         { return RBRACE; }
";"         { return SEMICOLON; }
[a-zA-Z_][a-zA-Z0-9_]*  { yylval.str = strdup(yytext); return IDENTIFIER; }
[0-9]+      { yylval.num = atoi(yytext); return NUMBER; }
[ \t\n]     ; /* skip whitespace */
.           { return yytext[0]; } /* For single characters like ( ) */
%%
```

### **Part 2: Bison Example (`c_parser.y` snippet)**
```bison
%{
#include <stdio.h>
void yyerror(const char *s) { fprintf(stderr, "Error: %s\n", s); }
extern int yylex();
%}

%token INT IF WHILE LBRACE RBRACE SEMICOLON
%token <str> IDENTIFIER
%token <num> NUMBER

%start program

%%

program:
    /* empty */
    | program function    { printf("<program>\n"); }
    ;

function:
    INT IDENTIFIER '(' ')' compound_statement { printf("<function><name>%s</name>%s</function>\n", $2, $5); }
    ;

compound_statement:
    LBRACE statements RBRACE { printf("<body>%s</body>", $2); }
    ;
// ... more rules for statements, expressions
%%
```

### **Part 3: Integration (Shell Commands)**
```bash
# Generate parser and header from Bison file
bison -d c_parser.y
# Generate lexer from Lex file
flex c_lexer.l
# Compile everything together
gcc -o c_to_xml c_parser.tab.c lex.yy.c -lfl
# Run the parser on a test file
./c_to_xml < test.c
```

### **Part 4: Applied Example - Expected XML Output**
**Input C file (`test.c`):**
```c
int main() {
    int x;
    x = 42;
}
```

**Target XML Output (simplified):**
```xml
<program>
<function>
    <name>main</name>
    <body>
        <declaration><type>int</type><name>x</name></declaration>
        <assignment><var>x</var><value>42</value></assignment>
    </body>
</function>
</program>
```
